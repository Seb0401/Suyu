# Suyu

App para turistas.

Suyu es una aplicación pensada para viajeros: ayuda a descubrir lugares, planificar
recorridos y aprovechar mejor el tiempo en el destino.

## Estado

Proyecto en desarrollo (hackathon Turiston). Este README es preliminar y se
actualizará con la documentación definitiva del proyecto.

## Objetivo

Facilitar la experiencia del turista en un destino:

- Descubrir puntos de interés cercanos
- Organizar itinerarios y rutas
- Acceder a información útil del lugar en un solo sitio

## Cómo empezar

```bash
git clone https://github.com/Seb0401/Suyu.git
cd Suyu
```

Las instrucciones de instalación y ejecución se agregarán cuando se defina el stack.
